# Planet X and SPHEREx

A planned public web tool for the [2026 NASA Space Apps Challenge](https://www.spaceappschallenge.org/2026/challenges/planet-x-and-spherex/). Enter sky coordinates and browse NASA SPHEREx observations on a timeline. Compare two dates, highlight changes, and inspect measured motion and uncertainty.

This repository currently contains the build specifications and live archive coverage research.

- [Build plan and milestones](BUILD_PLAN.md)
- [Measured availability for the five challenge targets](docs/OBSERVATION_AVAILABILITY.md)
- [Viewer, timeline and API](docs/VIEWER_AND_API.md)
- [Heatmap, detection, tracking, overlays and spectra](docs/COMPARISON_AND_TRACKING.md)
- [Same-server hosting and workload limits](docs/PRODUCTION_AND_BUDGETS.md)
- [Headless development and submission workflow](DEVELOPMENT.md)

The viewer will use SPHEREx DR1 and QR3 spectral images from NASA/IPAC IRSA. [IRSA archive guide](https://irsa.ipac.caltech.edu/spherex-archive-documentation/)
